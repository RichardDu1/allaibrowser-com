## Overview

AgentQL is an AI-native query language for web data extraction. Instead of writing complex CSS selectors or XPaths, you describe what you want in natural language, and AgentQL uses LLMs to understand the page and extract the data.

## Key Features

- **Natural Language Queries**: Describe data in plain English
- **AI Understanding**: LLMs interpret page content and structure
- **Structured Output**: Returns clean, structured data
- **Dynamic Content**: Handles JavaScript-rendered pages

## Why It Matters

AgentQL represents a paradigm shift in web scraping — instead of fighting with DOM selectors, you tell the AI what you want and it figures out how to get it. This makes it ideal for sites with frequently changing layouts.
