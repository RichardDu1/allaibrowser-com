## Overview

Personal trainers often spend hours crafting unique program descriptions for each client. This workflow uses AI to generate tailored descriptions based on client goals, fitness level, and preferences, then refines them for branding and visual appeal.

## Prerequisites

- A ChatGPT account (free or paid)
- A Canva account (free tier works)
- A Notion account (free) for organizing client data

## Step 1: Collect Client Information

Create a Notion database with fields: Name, Goal (e.g., weight loss, muscle gain), Fitness Level (beginner, intermediate, advanced), Preferred Style (e.g., HIIT, yoga, strength), and any special notes (injuries, equipment).

## Step 2: Generate Base Description with ChatGPT

Use a prompt like:

```
You are a professional fitness copywriter. Write a personalized program description for a client with the following details:
- Goal: [Goal]
- Fitness Level: [Level]
- Preferred Style: [Style]
- Notes: [Notes]

The description should be 100-150 words, motivational, and highlight the benefits of the program. Use a friendly but professional tone.
```

Copy the output into a new Notion page under the client.

## Step 3: Customize and Refine

Review the AI-generated text. Adjust to match your brand voice (e.g., add your signature phrases). Ensure accuracy of exercises and intensity. Use bold for key benefits.

## Step 4: Design Visual Program Card in Canva

Create a Canva template (800x1200 px) with your logo, program name, and a placeholder for description. Use a clean, modern layout. For each client, duplicate the template and paste the refined description. Add relevant stock images (e.g., a person doing the activity).

## Step 5: Export and Share

Download the design as a PDF or PNG. Share with the client via email or your client portal. Store the final description in Notion for future reference.

## Tips for Best Results

- Update your ChatGPT prompt with examples of your past descriptions for consistency.
- Use Canva's brand kit to maintain color scheme and fonts.
- Batch generate descriptions for multiple clients in one session to save time.
