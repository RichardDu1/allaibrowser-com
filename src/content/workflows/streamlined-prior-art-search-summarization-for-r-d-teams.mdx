## Overview

This workflow guides patent analysts through a systematic process to identify and summarize prior art relevant to a given patent or invention. By leveraging AI-powered search and summarization tools, you can dramatically reduce the time spent on manual searches and document review.

## Prerequisites

- A patent number or invention disclosure to analyze
- Access to the following tools (free tiers available):
  - **PatentGuru** for AI-enhanced patent search
  - **Scite.ai** for citation analysis and summarization
  - **Zotero** for reference management

## Step 1: Define the Search Scope

1. **Extract key concepts** from the patent or invention disclosure. Focus on:
   - Novel technical features
   - Problem solved
   - Key claims
2. **Create a search query** using Boolean operators and classification codes (e.g., CPC/IPC).
3. **Set date ranges** (e.g., before the priority date).

## Step 2: AI-Enhanced Patent Search with PatentGuru

1. **Open PatentGuru** (https://patentguru.com) and paste your search query.
2. **Enable AI semantic search** to find conceptually similar patents beyond keyword matches.
3. **Review the results** sorted by relevance. PatentGuru highlights key passages and provides a relevance score.
4. **Export the top 20-30 results** as a CSV or PDF list.

## Step 3: Citation Analysis with Scite.ai

1. **Go to Scite.ai** (https://scite.ai) and search for the target patent or key references.
2. **Use the 'Smart Citations'** feature to see how each reference has been cited (supporting, contrasting, or mentioning).
3. **Filter by citation context** to find prior art that directly challenges or supports the patent's novelty.
4. **Export the citation report** for further analysis.

## Step 4: Summarize Key Prior Art

1. **Select the most relevant patents** (typically 5-10) from the combined results.
2. **For each patent, use Scite.ai's summarization** feature to generate a concise abstract focusing on:
   - Technical problem
   - Solution approach
   - Key claims
3. **Alternatively, use PatentGuru's 'Summary'** button to get an AI-generated one-paragraph summary.

## Step 5: Organize and Store Results in Zotero

1. **Install Zotero** (https://www.zotero.org) and the browser connector.
2. **Create a new collection** named "Prior Art - [Patent Number]".
3. **Add each prior art document** by clicking the Zotero icon in your browser while viewing the patent page.
4. **Attach your summaries** as notes to each item.
5. **Tag items** with relevance level (High/Medium/Low) and key technical aspects.

## Step 6: Generate a Final Report

1. **In Zotero, select all items** in the collection.
2. **Right-click and choose 'Generate Report'** to create an HTML report with all metadata and notes.
3. **Export as PDF** and share with the R&D team.
4. **Include a summary table** with columns: Patent Number, Title, Relevance, Key Findings.

## Tips for Efficiency

- **Save search queries** in PatentGuru for reuse.
- **Use Zotero groups** to collaborate with team members.
- **Set up alerts** in PatentGuru for new prior art matching your query.

## Conclusion

By following this workflow, patent analysts can systematically identify and summarize prior art in a fraction of the time, enabling faster and more informed decisions for R&D teams.
